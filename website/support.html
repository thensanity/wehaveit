Support

How do I install it?

Install WeHaveIt from the Chrome Web Store. Pin it from the puzzle-piece menu so the icon stays visible.

How do I save an item?

Open a product page and click We have this on the bar, or click the extension and choose Save this page, or right-click the page and choose WeHaveIt: I already bought this.

The bar does not appear

It only appears on product pages, not search results or carts. Reload the page. If the shop is uncommon, use Save this page — Chrome will ask for permission for that site.

How do I delete my data?

Remove items from the popup list, or remove the extension in chrome://extensions. That deletes the local list from this browser.

Contact

Use the support option on the Chrome Web Store listing. Include the shop URL and a screenshot if something failed.
