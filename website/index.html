How it works

1. Buy something once Click We have this on the product page, or right-click any shop page and save it.
2. See it again later If you or someone in your home opens the same item, a bar appears: already bought.
3. Don’t pay twice Cables, vitamins, pans, printer ink. The boring stuff you forget you already have.

Works on most shops

Named support for the stores people actually open, plus a generic reader for Shopify, WooCommerce, and any page that looks like a product.

Install on Chrome (2 minutes)

  1. Open Chrome and go to chrome://extensions
  2. Turn on Developer mode
  3. Click Load unpacked and choose the extension folder in this project
  4. Open a product page on Shopee, Amazon, FairPrice, or any shop, or use the demo shop first

Chrome Web Store listing comes after this local version works on real shops.
